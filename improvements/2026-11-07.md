# 2026-11-07: weekly video-downloader update (roadmap item LC-01.2)

## What was done
Today was a roadmap day. The app downloads TikTok and YouTube videos with a tool that breaks every few weeks when those sites change. Now the app checks for a newer version of that tool every Sunday at 3:10 AM and starts using it right away, without anyone rebuilding the app.

## What behaves differently
- Every Sunday the app fetches the newest version of the downloader and keeps it in its data folder, so it survives restarts.
- The new version is tried first; if it does not start, the old one stays in place and the job reports the problem. A failed week changes nothing.
- Video downloads use the updated copy when there is one, and the version that came with the app otherwise.
- Link imports that do not need a video download are not affected.

## What was tested
- New tests: no updated copy means nothing changes; the updated copy is used first; a good update replaces the old one; a broken update keeps the old one; a network failure leaves no half-installed leftovers; the Sunday job is registered.
- All backend tests pass (397). Nothing in the app's screens changed, so no screenshots.
