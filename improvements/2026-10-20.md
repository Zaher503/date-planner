- The app would have shown this dinner as **free**. The text it used for the price was Eventbrite's own advert ("Create your event page for free"), not the event.
- The real price ($35 and up) was never missed by the page, it just never reached the import.
- The event is a year old and still shows as upcoming (not fixed, see below).

## What changed

Eventbrite pages hide the organizer's write-up from the normal page text, so the import only saw the site menus. It now reads the write-up as well and puts it first, so prices, times and details written by the organizer are visible to the price check.

## What it shows AFTER

No after screenshot (same reason as above, and a fix is not live until it is merged). Reading the same saved page with the new code now gives the organizer's text first, starting with "Tickets start at $35/per person including: movie pass, 3 course meal, unlimited popcorn". That is the text the price check will see, so the price should come out as $35 instead of "free". I could not rerun the full live import to confirm the final card.

## Still not fixed

- An event whose date is long past is still marked as upcoming. Suggestion: when the date is in the past, or the page says sales ended, mark it as ended so the app can hide it (touches how events are listed, so left for you to decide).
- The price check can still be fooled by the word "free" in a site's menus when a page has no price at all. Suggestion: only trust "free" from the event's own text, not the whole page.

## Technical notes

- `backend/app/ingest/event_page.py`: new `embedded_description()` reads `structuredContent.modules[type=text]` from the embedded page data and `parse_page` puts it before the trafilatura text. Eventbrite renders its description client-side, so trafilatura returned only nav/footer text (2k chars, no `$35`).
- Cause of the wrong price: `pricing.read_price` found no JSON-LD offers, then asked the model about nav text; "free" in the nav passed the "free appears in text" check.
- Tests: two new cases in `backend/tests/test_event_page.py`; ingest/pricing/page tests pass (60).
