# 2026-11-05: nightly backup of the database (`LC-01.1`)

Roadmap day (not an import check). Item: the first part of "scheduler basics", a nightly backup of everything saved in the app.

## What behaves differently
- Every night at 2:30 AM the app now saves a full copy of its database into the backups folder on the server, named like `dates-2026-11-05-0230.dump`.
- It keeps the newest 7 of these and deletes older ones. The hand-made backups from the 10-30 cleanup are never touched.
- A copy is written under a temporary name first, so a failed run never leaves a broken backup that looks real. A failed run is retried by the job queue.
- The app's server image now includes the Postgres 17 backup tool (same version as the database).

## Tested
- 6 new tests: the backup command (password kept off the command line), keeping 7 and leaving manual dumps alone, a good run, a failed run leaving nothing behind, a missing tool giving a clear message, and the job being scheduled. Whole backend suite: 397 passed.
