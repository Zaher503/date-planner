## What was done

`QA-01`: the automatic check that runs on every pull request now looks at more of the backend code. Before, it only caught code that would not run at all. Now it also catches imports that are never used, unused leftover variables, a few confusing code patterns, and imports in the wrong order. The 25 places it found today are fixed.

## What behaves differently

- Nothing changes in the app. Every fix only tidies code: imports are reordered or removed, one unused value is gone, and two small test helpers are rewritten.
- Future pull requests fail CI if they bring in an unused import or put imports out of order. The fix is one command (`ruff check --fix backend`).

## What was tested

- The backend tests pass both before and after the change (391 passed both times).
- The new check passes on the whole backend.
- No screenshots, because nothing in the app looks different.
